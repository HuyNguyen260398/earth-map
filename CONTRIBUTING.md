# Contributing

Thanks for your interest in Earth Map. Issues and pull requests are welcome.

## Setup

```sh
cd frontend
pnpm install
pnpm dev
```

Node.js 20.19+ or 22.12+ and pnpm are required.

## Before opening a pull request

Run both from `frontend/`:

```sh
pnpm test     # Vitest unit tests
pnpm build    # tsc type-check + production build
```

Please keep pull requests focused on one change, and describe what you changed
and how you verified it in the browser (band transitions and hover behaviour are
easy to break in ways tests don't catch).

## Code conventions

- TypeScript, no `any` escapes where a real type will do.
- Keep the pure modules pure: `navigation.ts`, `zoomLevels.ts`, `layers.ts`,
  `styles.ts`, `border.ts` and `geo.ts` have no rendering side effects and are
  unit-tested. New logic belongs there, wired up from `main.ts` — not inlined
  into the render path.
- Add or extend the matching `*.test.ts` when you change those modules.
- Comments explain *why*, not *what*. Several non-obvious constraints (ring
  winding, hysteresis thresholds, bundle-trimming aliases) are documented in
  comments — please keep them accurate if you touch that code.
- Commit messages follow the existing style: `type: imperative summary`
  (`feat:`, `fix:`, `perf:`, `docs:`).

## Changing map data

Do not hand-edit the GeoJSON in `frontend/public/data/`. It is generated by
`frontend/scripts/prepare-provinces.mjs` and `frontend/scripts/prepare-wards.mjs`;
update the script and re-run the pipeline documented in
[`frontend/public/data/README.md`](frontend/public/data/README.md), then note any
new source and its attribution there and in
[`LICENSE.md`](LICENSE.md).

> [!WARNING]
> Polygon rings must keep three-globe's winding — outer rings clockwise, holes
> counter-clockwise. Get this wrong and the globe renders as a flat blue sheet.
